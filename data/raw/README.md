# Raw Sequence Data

Raw FASTQ files for this study are deposited in the NCBI Sequence Read Archive
(SRA) under BioProject **PRJNA1523974**.

The data are public as of 2026-11-10:

- BioProject: <https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1523974>
- SRA Run Selector: <https://www.ncbi.nlm.nih.gov/Traces/study/?acc=PRJNA1523974>

The BioProject page can lag behind the SRA run release by a few days. If it
does not resolve yet, use the SRA Run Selector link.

## Sequencing Platform

- Platform: Oxford Nanopore Technologies (ONT)
- Library preparation: Native Barcoding Kit 24 V14
- Sequencer: MinION Mk1B
- Flow cells: R10.4.1 (FLO-MIN114)
- Basecalling: MinKNOW v25.03.9, high-accuracy mode
- Run duration: 72 hours

## Sample Scope

- Total samples in the study: 35 across all subsets S1-S4
- Samples in this repository (Subset S2): 18 samples from 9 mice
- Runs in SRA under PRJNA1523974: the 18 S2 samples listed below

## Download Instructions

Download the raw SRA/FASTQ data with
[code/hpc/03_download_sra_fastq.sh](../../code/hpc/03_download_sra_fastq.sh).
It names each FASTQ by sample ID (for example `OPA01.fastq`) to match the
metadata and
[`02_kraken2_array_core_nt.slurm`](../../code/hpc/02_kraken2_array_core_nt.slurm),
and writes the SRR-to-sample map to `srr_to_sample.tsv`:

```bash
bash code/hpc/03_download_sra_fastq.sh data/fastq
```

Requires the SRA Toolkit (`prefetch`, `fasterq-dump`) and Entrez Direct
(`esearch`, `efetch`). The total download is about 11 GB of `.sra` files.

The 18 `.k2report` files generated by Kraken2 and needed to reproduce the
figures are already included in
[`data/kraken_reports_core_nt/`](../kraken_reports_core_nt/).
