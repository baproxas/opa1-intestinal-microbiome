Kraken2 Database and Sequencing Software Versions

-----------------------
Name: k2_host_db
Contents: GRCm39 (mouse) + GRCh38 (human) reference genomes

Location on HPC: /xdisk/vkv/baproxas/opa1_drp/data/db/k2_host_db

2. Pass 2 Classification Database
---------------------------------
Name: k2_core_nt_20251015
Release date: October 15, 2025
Source URL: https://genome-idx.s3.amazonaws.com/kraken/k2_core_nt_20251015.tar.gz
Contents: NCBI core_nt (GenBank, RefSeq, TPA, PDB nucleotide sequences)
Index size: ~316 GB
Confidence threshold: 0.01
Location on HPC: /xdisk/vkv/baproxas/opa1_drp/data/db/k2_core_nt_20251015

3. Two-Pass Classification Strategy
------------------------------------
Pass 1: Classify against the host database and extract unclassified (non-host) reads.
Pass 2: Classify non-host reads against core_nt and generate .k2report files.
Post-processing: Retain only Bacteria and Archaea; remove human, organelle, and
eukaryotic taxa.
